# ⚡️ Elegram — سلف‌بات هوشمند آرشیو مدیا در تلگرام

سلف‌بات شخصی متصل به اکانت تلگرام شما برای **آرشیو خودکار و نامحدود** رسانه‌ها:

- 🛡 **عبور از قفل فوروارد** — محتوای کانال‌های ضدفوروارد را دانلود و به‌صورت فایل مستقل با متادیتای کامل در Saved Messages ذخیره می‌کند (ابتدا ارسال مستقیم مرجع رسانه امتحان می‌شود؛ اگر مسدود بود، دانلود + بازآپلود انجام می‌شود).
- ⏳ **شکار رسانه‌های محوشونده (TTL)** — عکس/ویدیوی تایم‌دار بلافاصله و با بالاترین اولویت دانلود و ذخیره می‌شود.
- 🗂 **پشتیبانی کامل آلبوم و همه فرمت‌ها** — عکس، ویدیو، گیف، استیکر، وویس، ویدیومسیج، آهنگ، داکیومنت؛ بدون افت کیفیت.
- 🔁 **سیو خودکار چت‌ها** — فعال‌سازی per-chat بدون دخالت دست.
- 🎮 **کنترل از طریق Saved Messages** با UI فارسی و کارت‌های گرافیکی.
- 💾 **Zero-DB** — تنظیمات و آمار روی فایل JSON محلی.
- ☁️ **آماده Railway** — وب‌سرور داخلی Health-check روی پورت `PORT`.

---

## 🚀 راه‌اندازی سریع

### ۱. نصب

```bash
npm install
```

### ۲. دریافت API_ID و API_HASH

1. وارد [my.telegram.org](https://my.telegram.org) شوید.
2. بخش **API development tools** → یک اپلیکیشن بسازید.
3. مقادیر `api_id` و `api_hash` را کپی کنید.

### ۳. ساخت SESSION

```bash
npm run login
```

شماره تلفن، کد دریافتی و (در صورت وجود) رمز دو مرحله‌ای را وارد کنید. رشته خروجی را کپی کنید.

### ۴. تنظیم متغیرها

فایل `.env.example` را به `.env` کپی و تکمیل کنید:

| متغیر | الزامی | توضیح |
| :--- | :--- | :--- |
| `API_ID` | ✅ | از my.telegram.org |
| `API_HASH` | ✅ | از my.telegram.org |
| `SESSION` | ✅ | خروجی `npm run login` |
| `STORAGE_PEER` | ❌ | مقصد آرشیو؛ پیش‌فرض `me` (Saved Messages). می‌تواند یوزرنیم کانال شخصی باشد مثل `@myarchive` |
| `PORT` | ❌ | پورت وب‌سرور Health-check (پیش‌فرض 3000) |
| `DATA_DIR` | ❌ | محل ذخیره داده‌ها (پیش‌فرض `./data`) |

### ۵. اجرا

```bash
npm start
```

## 🎮 دستورات

دستورات را در هر چتی می‌توانید بفرستید (معمولاً داخل Saved Messages):

| دستور | عملکرد |
| :--- | :--- |
| `/ping` | تأخیر اتصال + آپ‌تایم |
| `/save` | ریپلای روی پیام/آلبوم → آرشیو با متادیتای کامل |
| `/auto on` \| `/auto off` | فعال/غیرفعال‌سازی سیو خودکار همان چت |
| `/autolist` | لیست چت‌های دارای سیو خودکار |
| `/status` | تعداد فایل‌ها، حجم کل، وضعیت صف، مصرف RAM |
| `/help` | راهنمای کامل |

> 💡 برای رسانه‌های TTL هیچ دستوری لازم نیست؛ به محض دریافت، خودکار شکار می‌شوند.

## ☁️ دیپلوی روی Railway

1. پروژه را روی GitHub قرار دهید.
2. در [Railway](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
3. در تب **Variables** این متغیرها را بسازید: `API_ID`, `API_HASH`, `SESSION`.
4. Deploy بگیرید — فایل `nixpacks.toml` نسخه Node 20 را تضمین و `src/index.js` را اجرا می‌کند.
5. Health-check: مسیر `/health` روی پورت اختصاص‌یافته Railway پاسخ JSON می‌دهد.

> ⚠️ **نکته:** سلف‌بات‌ها استفاده غیررسمی از اکانت هستند؛ استفاده متعهدانه و بدون اسپم توصیه می‌شود تا اکانت دچار محدودیت (FloodWait) نشود.

## 🧱 ساختار پروژه

```
src/
├── index.js              # نقطه ورود — اتصال، راه‌اندازی، خاموشی امن
├── config.js             # متغیرهای محیطی
├── login.js              # اسکریپت تولید StringSession
├── store.js              # پایداری تنظیمات/آمار روی JSON
├── server.js             # وب‌سرور Health-check
├── handlers/
│   ├── messages.js       # دیسپچر رویدادها (کامند/ورودی/TTL)
│   └── commands.js       # منطق دستورات
├── services/
│   ├── archiver.js       # موتور دانلود→آپلود با Progress
│   ├── mediaInfo.js      # تشخیص نوع رسانه، TTL، نام فایل، لینک منبع
│   ├── queue.js          # صف اولویت‌دار
│   └── albums.js         # بافر تجمیع آلبوم‌ها
└── ui/
    └── cards.js          # قالب‌های پیام (UI/UX)
```
