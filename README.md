# ⚡️ Elegram

**یه دستیار شخصی برای تلگرام که هر عکس و ویدیویی رو که بخوای، برات نگه می‌داره — و حالا هر پیامی رو هم که ممکنه پاک بشه.**

می‌دونی اون عکس‌هایی که فقط یه بار باز میشن و بعد پاک میشن؟ یا کانال‌هایی که نمی‌شه ازشون فوروارد یا سیو کرد؟ یا اون پیامی که طرف فرستاد و دو ثانیه بعد پاکش کرد؟ Elegram همه‌شون رو برات نگه می‌داره و به‌عنوان یه نسخه دائمی می‌ذاره داخل **Saved Messages** خودت. همین.

از نسخه ۲.۳ هم لازم نیست همه‌چیز رو با دستور تایپی بچرخونی: یه **پنل کنترل شیشه‌ای** داری که با دکمه کار می‌کنه. [راهنمای کامل پنل →](docs/PANEL.md)

## Elegram دقیقاً چیکار می‌کنه؟

| قابلیت | یعنی چی؟ |
| :--- | :--- |
| 🎛 **پنل کنترل شیشه‌ای (جدید)** | یه پنل دکمه‌ای کامل: داشبورد، لیست چت‌ها با صفحه‌بندی، صف، آمار، تنظیمات زنده، ذخیره با لینک، و تأیید دومرحله‌ای برای هر حذف. `.panel` رو بفرست تا بازش کنی. |
| 🪞 **آینه پیام‌ها** | روی هر چت، گروه یا کانالی که بخوای، هر پیام همون لحظه توی آرشیوت کپی میشه. طرف پیامش رو **ویرایش** کرد؟ نسخه قبلی و جدید کنار هم ثبت میشه. **پاک** کرد؟ متن اصلی هنوز پیش توئه. |
| 📡 **کانال و گروهی که نمی‌شه توش نوشت** | لازم نیست دستور رو داخل اون چت بفرستی. از Saved Messages خودت بنویس `.mirror @channel` یا `.mirror -1001234567890`. حذف هم همون‌قدر ساده: `.mirror off @channel`. |
| 🛡 **سیو از کانال‌های قفل‌شده** | کانال‌هایی که دکمه سیو و فوروارد رو بسته‌اند، بازم می‌تونی محتواشون رو نگه داری. |
| 🔗 **سیو با لینک پست** | جایی که نمی‌شه پیام فرستاد یا ریپلای کرد (کانال‌های فقط-خواندنی)، فقط لینک پست رو جلوی `.save` بذار — یا از پنل، دکمه «ذخیره با لینک». |
| 🤫 **بی‌سروصدا در گروه‌ها** | دستور `.save` توی گروه فوراً پاک میشه و همه گزارش‌ها فقط توی Saved Messages نوشته میشه. |
| ⏳ **گرفتن عکس‌های یک‌بارمصرف** | اون عکس/ویدیوهایی که بعد از دیدن محو میشن، بلافاصله و اتوماتیک ذخیره میشن. نسخه‌ای که Elegram سیو می‌کنه هیچ‌وقت پاک نمیشه. |
| 🗂 **همه‌چیز رو می‌گیره** | عکس، ویدیو، گیف، استیکر، ویس، ویدیومسیج، آهنگ، فایل. آلبوم‌های چندتایی هم کامل. |
| ✨ **بدون افت کیفیت** | فایل اصلی سیو میشه، نه نسخه فشرده. |
| 🔁 **حالت خودکار** | می‌تونی بگی «هر چی توی این چت اومد، خودکار سیو کن». |
| 🎮 **کنترل از داخل تلگرام** | با چندتا دستور ساده، یا با دکمه‌های پنل، همه‌چیز رو مدیریت می‌کنی. |
| 💾 **بدون دیتابیس** | نیازی به نصب هیچ دیتابیسی نیست. |

> ⚠️ **قبل از شروع اینو بخون:** Elegram به اکانت خودت وصل میشه (به این میگن «سلف‌بات»). این کار از نظر تلگرام رسمی نیست، پس منطقی استفاده کن: اسپم نکن و هزارتا فایل رو یه‌جا سیو نکن، وگرنه ممکنه تلگرام موقتاً محدودت کنه.

> 🔴 **تغییر مهم در نسخه ۲.۱:** دستورها دیگه با `/` شروع نمی‌شن، با **نقطه** شروع می‌شن: `.save`، `.status`، `.help`. دلیلش هم اینه که `/` پیشوند همه ربات‌هاست و توی گروه‌ها با اون‌ها تداخل می‌کرد.

> 🟢 **جدید در نسخه ۲.۲:** `.mirror` و `.auto` دیگه لازم نیست داخل خود چت فرستاده بشن. یوزرنیم یا شناسه عددی رو جلوی دستور بذار — همون چیزی که برای کانال‌ها و گروه‌های فقط-خواندنی لازم بود.

> 🟣 **جدید در نسخه ۲.۳:** بازطراحی کامل ظاهر (یه سیستم طراحی مشترک برای همه کارت‌ها) + **پنل کنترل شیشه‌ای** روی یه ربات همراه. دکمه‌های شیشه‌ای در تلگرام فقط برای ربات‌ها ممکن‌اند، پس پنل روی رباتِ خودت کشیده میشه و کارها همون‌طور با اکانت خودت انجام میشه. اختیاریه: `BOT_TOKEN` رو خالی بذار و هیچ‌چیز کم نمیشه.

## 🚀 راه‌اندازی (قدم به قدم)

اگه تا حالا هیچ‌وقت پروژه‌ای رو اجرا نکردی، نگران نباش. فقط این ۶ قدم رو به ترتیب انجام بده.

### قدم ۰ — Node.js رو نصب کن

Elegram با Node.js اجرا میشه. برو به [nodejs.org](https://nodejs.org) و نسخه پیشنهادی (LTS) رو نصب کن. **حداقل نسخه ۲۰ لازمه.**

```bash
node -v
```

اگه یه چیزی مثل `v20.11.0` یا بالاتر دیدی، عالیه.

### قدم ۱ — پروژه رو بگیر و پکیج‌ها رو نصب کن

```bash
git clone https://github.com/MrMatin0/elegram.git
cd elegram
npm install
```

اگه `git` نداری، از صفحه گیت‌هاب دکمه **Code → Download ZIP** رو بزن، فایل رو از حالت زیپ دربیار، بعد ترمینال رو داخل همون پوشه باز کن و فقط `npm install` رو اجرا کن.

### قدم ۲ — از تلگرام دو تا کد بگیر (API_ID و API_HASH)

1. برو به [my.telegram.org](https://my.telegram.org) و با شماره تلگرام خودت وارد شو.
2. روی **API development tools** کلیک کن.
3. فرم رو پر کن (اسم اپ هر چیزی می‌تونه باشه، مثلاً `elegram`).
4. دو تا مقدار به اسم `api_id` و `api_hash` می‌بینی. اینا رو یه جا کپی کن.

### قدم ۳ — فایل تنظیمات رو بساز

```bash
# مک و لینوکس
cp .env.example .env

# ویندوز
copy .env.example .env
```

حالا `.env` رو باز کن و `API_ID` و `API_HASH` رو با همون مقادیر قدم ۲ پر کن. `SESSION` رو فعلاً خالی بذار.

> 🔒 فایل `.env` اطلاعات خصوصی توئه. هیچ‌وقت جایی آپلودش نکن.

### قدم ۴ — یه بار به اکانتت لاگین کن

```bash
npm run login
```

ازت شماره تلفن، کد تایید و (اگر داشتی) رمز دو مرحله‌ای می‌پرسه. آخرش یه رشته طولانی برات چاپ می‌شه — **کاملش رو کپی کن** و توی `.env` بذارش جلوی `SESSION=`:

```
SESSION=1BQANOTEuMTA4LjU2LjE...
```

این کار فقط یه بار لازمه. این رشته حکم «کلید ورود» رو داره، پس مثل رمز عبور ازش مراقبت کن.

### قدم ۵ — اجراش کن

```bash
npm start
```

همین! حالا برو توی تلگرام، **Saved Messages** خودت رو باز کن و بنویس `.ping`. اگه پیامت تبدیل شد به یه کارت با اطلاعات اتصال، یعنی همه‌چیز درست کار می‌کنه. 🎉

### قدم ۶ (اختیاری) — پنل شیشه‌ای رو روشن کن

1. از [@BotFather](https://t.me/BotFather) یه ربات بساز و توکنش رو بگیر.
2. توی `.env` بذار: `BOT_TOKEN=123456:ABC-DEF...`
3. سرویس رو ری‌استارت کن، بعد توی Saved Messages بنویس `.panel` و لینک رو باز کن.

فقط خودت به پنل دسترسی داری. اگه می‌خوای مالک پنل یه اکانت دیگه باشه، `PANEL_OWNER` رو با شناسه عددیش پر کن (شناسه‌ات رو با `.id` می‌گیری).

## 🎛 پنل کنترل شیشه‌ای

دکمه‌های شیشه‌ای (inline) در تلگرام **فقط برای ربات‌ها** ممکن‌اند: یه اکانت کاربری اگه به پیامش کیبورد وصل کنه، تلگرام بی‌صدا حذفش می‌کنه و کلیک هم به هیچ‌جا نمی‌رسه. پس Elegram کار رو بین دو هویت تقسیم می‌کنه:

| کار | با چه هویتی |
| :--- | :--- |
| خوندن چت‌های محافظت‌شده، شکار رسانه محوشونده، آرشیو کردن | **اکانت خودت** |
| کشیدن پنل، دکمه، صفحه‌بندی، تأیید دومرحله‌ای | **ربات همراه** |

ربات هیچ دسترسی‌ای به آرشیو تو نداره و خودش هیچ کاری انجام نمی‌ده؛ فقط صفحه‌نمایشه.

توی پنل چی هست:

- **داشبورد** — وضعیت اتصال، آپ‌تایم، تعداد و حجم آرشیو، بار صف، تعداد چت‌های فعال.
- **سیو خودکار / آینه** — لیست چت‌ها با صفحه‌بندی؛ هر چت یه صفحه جزئیات با کلید روشن/خاموش برای هر دو قابلیت.
- **صف** — بار کارگرها، نرخ موفقیت، و پاک کردن صف (با تأیید).
- **آمار** — میانگین حجم هر فایل، نرخ موفقیت، شمارنده‌های آینه، مصرف حافظه.
- **ابزارها** — ذخیره با لینک پست، افزودن چت به آینه یا سیو خودکار (فقط یوزرنیم/شناسه رو بفرست).
- **تنظیمات زنده** — همزمانی آرشیو ‎−/+‎، روشن/خاموش کردن ری‌اکشن، چرخش سطح لاگ. (تا ری‌استارت بعدی می‌مونن.)

دستورهای ربات: `/panel` `/status` `/queue` `/id` `/help`

جزئیات معماری و سیستم طراحی: [`docs/PANEL.md`](docs/PANEL.md)

## 🎮 دستورات

دستورات رو مثل یه پیام معمولی می‌فرستی (معمولاً توی Saved Messages خودت). پیامت جای اینکه بمونه، تبدیل به جواب میشه.

**همه دستورها با نقطه شروع میشن، نه با اسلش.** این یه تصمیم عمدیه: `/` پیشوند ربات‌هاست و توی گروه‌ها هم اون‌ها جوابش رو می‌دن، هم کلاینت تلگرام روش لیست دستورات باز می‌کنه.

| دستور | کارش چیه؟ |
| :--- | :--- |
| `.save` | **مهم‌ترین دستور.** روی اون عکس/ویدیو/فایلی که می‌خوای ریپلای کن و بفرست `.save`. |
| `.save <لینک پست>` | همون کار، ولی بدون ریپلای. برای کانال‌هایی که نمی‌شه توشون پیام فرستاد یا فورواردشون بسته‌است: `.save https://t.me/channel/1234` — کانال خصوصی هم: `.save https://t.me/c/1234567890/1234` |
| `.panel` | **لینک پنل شیشه‌ای.** اگه `BOT_TOKEN` تنظیم نشده باشه، توضیح می‌ده چطور روشنش کنی. |
| `.id` | شناسه همین چت (و شناسه خودت) — آماده‌ی کپی برای `.mirror` و `.auto` و `PANEL_OWNER`. |
| `.auto on` | «از این به بعد هر رسانه‌ای توی این چت اومد، خودکار سیو کن.» |
| `.auto off` | خاموش کردن حالت خودکار برای همون چت. |
| `.auto <یوزرنیم یا شناسه>` | روشن کردن حالت خودکار برای یه چت دیگه، از هر جا: `.auto @channel` یا `.auto -1001234567890` |
| `.auto off <یوزرنیم یا شناسه>` | حذف همون چت از لیست خودکار. |
| `.autolist` | ببین کدوم چت‌ها حالت خودکارشون روشنه (با شناسه، آماده کپی). |
| `.mirror on` | **آینه روشن کن.** هر پیام این چت لحظه‌ای در آرشیو کپی میشه و ویرایش/حذفش ثبت میشه. |
| `.mirror off` | خاموش کردن آینه همون چت. هر چی تا حالا ثبت شده سر جاش می‌مونه. |
| `.mirror <یوزرنیم یا شناسه>` | **برای کانال‌ها و گروه‌های فقط-خواندنی.** آینه رو از هر جا روشن کن: `.mirror @channel` یا `.mirror -1001234567890` |
| `.mirror off <یوزرنیم یا شناسه>` | حذف همون چت از لیست آینه، بدون اینکه لازم باشه بری داخلش. |
| `.mirrorlist` | ببین کدوم چت‌ها آینه شده‌اند (با شناسه، آماده کپی). |
| `.status` | چند فایل سیو شده، چه حجمی، چند تا در صف، آمار آینه، مصرف حافظه. |
| `.cancel` | پاک کردن صف انتظار (کارهای در حال اجرا متوقف نمی‌شن). |
| `.ping` | چک کن که زنده و وصله. |
| `.help` | راهنمای کامل داخل تلگرام. |

### 📡 روشن کردن آینه روی کانال و گروهی که نمی‌شه توش نوشت

`.mirror on` باید داخل خود چت فرستاده بشه — و توی کانال (یا گروهی که اجازه ارسال نداری) اصلاً نمی‌تونی چیزی بنویسی. پس اسم چت رو جلوی دستور بذار و از **Saved Messages** خودت بفرست:

```
.mirror @channel                       # یوزرنیم عمومی (با @ یا بی @)
.mirror -1001234567890                 # شناسه عددی، همون‌جوری که تلگرام می‌ده
.mirror https://t.me/channel           # لینک چت
.mirror https://t.me/channel/1234      # لینک یه پست از همون چت هم قبوله
.mirror https://t.me/c/1234567890      # کانال خصوصی
```

و برای حذف از لیست:

```
.mirror off @channel
.mirror off -1001234567890
```

نکته‌ها:

- بدون `on` و `off`، یه هدف تنها یعنی **روشن کن**: `.mirror @channel` همون `.mirror on @channel` است.
- شناسه عددی رو از `.mirrorlist` (یا `.autolist`) بردار؛ هر ردیف شناسه‌اش رو کنارش نشون می‌ده و می‌تونی کپی کنی. توی پنل هم همین کار با دکمه «افزودن چت» انجام میشه.
- شناسه کانال باید کامل و با `-100` باشه (`-1001234567890`). یه عدد بدون علامت ممکنه کاربر باشه، ممکنه کانال؛ اگه چت رو نشناسه، ازت شکل کامل رو می‌خواد.
- برای چت **خصوصی** باید با همین اکانت عضوش باشی. اگه گفت «این چت را پیدا نکردم»، یه بار چت رو توی تلگرام باز کن و دوباره امتحان کن.
- `.auto` هم دقیقاً همین شکل‌ها رو می‌پذیره.
- حذف از لیست حتی برای چتی که ازش بیرون اومدی یا پاک شده هم کار می‌کنه: شناسه‌ای که توی لیست هست، بدون هیچ درخواستی به تلگرام حذف میشه.

### 🪞 آینه (Mirror) — پیام پاک‌شده و ویرایش‌شده

توی چتی که می‌خوای `.mirror on` رو بفرست (یا از بیرون، `.mirror @channel`). از اون لحظه:

- **هر پیام جدید** یه کارت تمیز توی آرشیوت می‌سازه: اسم چت، فرستنده، زمان، و متن کامل پیام.
- **ویرایش شد؟** یه کارت جدید به‌صورت **ریپلای روی همون کپی اصلی** می‌آد که نسخه قبلی و نسخه فعلی رو کنار هم نشون می‌ده (و اگه چند بار ویرایش شده باشه، نسخه اول رو هم).
- **پاک شد؟** یه کارت «پیام پاک شد» می‌آد که **متن اصلی** رو نگه داشته، با زمان اصلی و زمان حذف.
- **رسانه‌ها** هم خودکار آرشیو میشن، پس عکس پاک‌شده هم مثل متن پاک‌شده پیش خودت می‌مونه.
- توی **گروه** و **کانال** هم دقیقاً همین‌طور کار می‌کنه.

همه کارت‌ها به‌صورت یه رشته (thread) زیر همون کپی اصلی جمع میشن، پس تاریخچه یه پیام رو یه‌جا می‌خونی.

**نکته‌های واقع‌بینانه:**

- آینه فقط پیام‌هایی رو می‌شناسه که **در زمان اجرای Elegram** دیده باشه. پیام‌های قبل از روشن کردن آینه (یا وقتی سرویس خواب بود) قابل بازیابی نیستن — تلگرام محتوای پیام پاک‌شده رو به هیچ‌کس نمی‌ده.
- تاریخچه در حافظه (RAM) نگه داشته میشه: آخرین ۴۰۰۰ پیام هر بار اجرا. بعد از ری‌استارت، کپی‌های آرشیوشده سر جاشون هستن ولی رهگیری ویرایش/حذف از صفر شروع میشه.
- روی یه گروه شلوغ، آینه یعنی **کلی پیام در آرشیو**. ارسال‌ها صف‌بندی و کُندسازی شده‌اند تا تلگرام محدودت نکنه، ولی بازم گروه پرترافیک رو با فکر آینه کن.
- Saved Messages رو نمی‌تونی آینه کنی (خودش مقصد آرشیوه).

### 🔗 سیو با لینک پست

لینک رو از تلگرام با **Copy Link** بردار و جلوی دستور بذار. همه این شکل‌ها قبول میشه:

```
.save https://t.me/channel/1234              # کانال یا گروه عمومی
.save https://t.me/c/1234567890/1234         # کانال خصوصی
.save https://t.me/group/45/1234             # داخل تاپیک (شماره آخر، همون پست)
.save t.me/channel/1234                      # بدون https هم مشکلی نیست
```

نکته‌ها:

- برای کانال **خصوصی** باید با همین اکانت عضوش باشی. اگه گفت «به این چت دسترسی ندارم»، یه بار چت رو توی تلگرام باز کن و دوباره امتحان کن.
- اگه لینک به یه آلبوم چندتایی باشه، کل آلبوم سیو میشه، نه فقط یه آیتم.
- خود دستور رو می‌تونی راحت توی Saved Messages بفرستی؛ لازم نیست بری داخل اون کانال.
- از پنل هم همین کار با دکمه «ذخیره با لینک» انجام میشه.

**چند نکته دیگه:**

- توی گروه‌ها (و هر چتی جز Saved Messages) پیام `.save` **بلافاصله پاک میشه** و کارت صف/دانلود/آپلود توی Saved Messages نوشته میشه، نه اون گروه. پس هیچ‌کس نمی‌فهمه.
- برای عکس‌های **یک‌بارمصرف** لازم نیست کاری بکنی. به محض رسیدنشون خودکار و با بالاترین اولویت سیو میشن.
- `.auto on` و `.mirror on` رو داخل Saved Messages نمی‌تونی روشن کنی (منطقی هم هست، خودش مقصد آرشیوه) — ولی شکل هدف‌دارشون (`.mirror @channel`) دقیقاً برای همین‌جا ساخته شده.

## ☁️ روشن نگه داشتنش ۲۴ ساعته (با Railway)

1. یه کپی (Fork) از این پروژه توی گیت‌هاب خودت بساز.
2. توی Railway بزن **New Project → Deploy from GitHub repo** و همون پروژه رو انتخاب کن.
3. برو تب **Variables** و این سه تا رو اضافه کن: `API_ID`، `API_HASH`، `SESSION`. (اگه پنل می‌خوای، `BOT_TOKEN` رو هم اضافه کن.)
4. Deploy کن. تمام.

دو تا آدرس برای پایش وجود داره:

| مسیر | کارش |
| :--- | :--- |
| `/health` (یا `/`) | **liveness** — تا وقتی پروسه زنده‌است ۲۰۰ میده، حتی وقتی هنوز داره به تلگرام وصل میشه. اینو به Railway بده. |
| `/ready` | **readiness** — تا وقتی لاگین تأیید نشده ۵۰۳ میده. برای مونیتورینگ دقیق‌تر. |

خروجی JSON علاوه بر آمار آرشیو، شمارنده‌های آینه رو هم می‌ده: `mirrorChats`، `mirrored`، `mirrorEdits`، `mirrorDeletes` — و `panel` که می‌گه پنل شیشه‌ای بالا هست یا نه. (`false` یعنی تنظیم نشده، نه خرابی.)

## 🩺 مشکل خوردی؟

**دستورهام هیچ کاری نمی‌کنن**
از نسخه ۲.۱ پیشوند دستورها از `/` به `.` عوض شده. `.help` رو امتحان کن.

**پنل بالا نمیاد / `.panel` می‌گه تنظیم نشده**
`BOT_TOKEN` توی `.env` خالیه یا شکلش درست نیست (باید مثل `123456:ABC-DEF...` باشه). بعد از پر کردنش سرویس رو ری‌استارت کن. اگه توکن رو تلگرام رد کنه، توی لاگ می‌بینی و آرشیو بدون پنل ادامه می‌ده.

**پنل به من جواب نمی‌ده**
پنل فقط به مالکش جواب می‌ده. اگه `PANEL_OWNER` رو دستی پر کرده‌ای، مطمئن شو شناسه‌ی درستیه — با `.id` بگیرش.

**توی کانال نمی‌تونم `.mirror on` بفرستم**
لازم هم نیست. از Saved Messages خودت بنویس `.mirror @channel` یا `.mirror -1001234567890`. برای خاموش کردنش هم `.mirror off @channel`. یا از پنل، دکمه «افزودن چت».

**`ERR_PACKAGE_PATH_NOT_EXPORTED`**
داری یه نسخه قدیمی رو اجرا می‌کنی. پکیج teleproto ایمپورت رو فقط به شکل `teleproto/sessions` قبول می‌کنه، نه `teleproto/sessions/index.js`. از نسخه ۲ به بعد درست شده — `git pull` بزن.

**«متغیر محیطی API_ID تنظیم نشده است»**
فایل `.env` رو نساختی یا خالیه. برگرد به قدم ۳.

**«متغیر SESSION خالی است»**
قدم ۴ رو انجام بده و اون رشته طولانی رو داخل `.env` بذار.

**«SESSION نامعتبر یا منقضی است»**
احتمالاً از تلگرام (Settings → Devices) سشنو ترمینیت کردی. دوباره `npm run login` بزن.

**«این یک لینک پیام تلگرام نیست»**
لینک ناقصه. باید آخرش شماره پیام داشته باشه (`.../1234`)، نه فقط اسم کانال.

**«به این چت دسترسی ندارم»**
کانال خصوصیه و اکانتت عضوش نیست، یا هنوز اون چت رو با این سشن ندیده. عضو شو، یه بار چت رو باز کن، بعد دوباره `.save` بزن.

**«این چت را پیدا نکردم»**
یوزرنیم/شناسه‌ای که برای `.mirror` یا `.auto` دادی قابل دسترسی نیست. شناسه کانال رو کامل و با `-100` بده، یا اول یه بار چت رو توی تلگرام باز کن تا سشن بشناسدش.

**آینه روشنه ولی ویرایش/حذف ثبت نمیشه**
آینه فقط برای پیام‌هایی کار می‌کنه که خودش دیده باشه. اگه پیام قبل از روشن شدن سرویس (یا قبل از `.mirror on`) فرستاده شده، تلگرام دیگه محتواش رو نمی‌ده. توی لاگ هم چک کن که هندلر ویرایش/حذف غیرفعال نشده باشه.

**`npm` یا `node` شناخته نمی‌شه**
Node.js نصب نیست یا بعد از نصب، ترمینال رو نبستی.

**پیام میدم ولی هیچ اتفاقی نمی‌افته**
مطمئن شو `npm start` هنوز داره اجرا میشه. اول با `.ping` تست کن، بعد با `LOG_LEVEL=debug` اجراش کن تا دقیقاً ببینی کجا گیر کرده.

**سیو کردن وسط کار متوقف شد یا کند شد**
احتمالاً تلگرام موقتاً محدودت کرده (FloodWait). خودش صبر می‌کنه و مجدد تلاش می‌کنه. برای اینکه کمتر پیش بیاد، `CONCURRENCY` رو بذار `1` (از پنل هم می‌تونی همون لحظه کمش کنی).

**فایل‌های بزرگ خیلی طول می‌کشن**
طبیعیه. Elegram اول دانلود می‌کنه بعد آپلود. `UPLOAD_WORKERS` رو ببر روی `8` تا قطعات موازی برن.
