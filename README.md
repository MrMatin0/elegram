# ⚡️ Elegram

**یه دستیار شخصی برای تلگرام که هر عکس و ویدیویی رو که بخوای، برات نگه می‌داره.**

می‌دونی اون عکس‌هایی که فقط یه بار باز میشن و بعد پاک میشن؟ یا کانال‌هایی که نمی‌شه ازشون فوروارد یا سیو کرد؟ Elegram اون‌ها رو برات دانلود می‌کنه و به‌عنوان یه فایل معمولی و دائمی می‌ذاره داخل **Saved Messages** خودت. همین.

---

## Elegram دقیقاً چیکار می‌کنه؟

| قابلیت | یعنی چی؟ |
| :--- | :--- |
| 🛡 **سیو از کانال‌های قفل‌شده** | کانال‌هایی که دکمه سیو و فوروارد رو بسته‌اند، بازم می‌تونی محتواشون رو نگه داری. |
| ⏳ **گرفتن عکس‌های یک‌بارمصرف** | اون عکس/ویدیوهایی که بعد از دیدن محو میشن، بلافاصله و اتوماتیک ذخیره میشن. نسخه‌ای که Elegram سیو می‌کنه هیچ‌وقت پاک نمیشه. |
| 🗂 **همه‌چیز رو می‌گیره** | عکس، ویدیو، گیف، استیکر، ویس، ویدیومسیج، آهنگ، فایل. آلبوم‌های چندتایی هم کامل. |
| ✨ **بدون افت کیفیت** | فایل اصلی سیو میشه، نه نسخه فشرده. |
| 🔁 **حالت خودکار** | می‌تونی بگی «هر چی توی این چت اومد، خودکار سیو کن». |
| 🎮 **کنترل از داخل تلگرام** | با چندتا دستور ساده، همه‌چیز رو از Saved Messages مدیریت می‌کنی. |
| 💾 **بدون دیتابیس** | نیازی به نصب هیچ دیتابیسی نیست. |

> ⚠️ **قبل از شروع اینو بخون:** Elegram به اکانت خودت وصل میشه (به این میگن «سلف‌بات»). این کار از نظر تلگرام رسمی نیست، پس منطقی استفاده کن: اسپم نکن و هزارتا فایل رو یه‌جا سیو نکن، وگرنه ممکنه تلگرام موقتاً محدودت کنه.

## 🚀 راه‌اندازی (قدم به قدم)

اگه تا حالا هیچ‌وقت پروژه‌ای رو اجرا نکردی، نگران نباش. فقط این ۶ قدم رو به ترتیب انجام بده.

### قدم ۰ — Node.js رو نصب کن

Elegram با Node.js اجرا میشه. برو به [nodejs.org](https://nodejs.org) و نسخه پیشنهادی (LTS) رو نصب کن. **حداقل نسخه ۲۰ لازمه.**

برای اینکه مطمئن شی نصب شده، ترمینال (روی ویندوز: PowerShell یا CMD) رو باز کن و بزن:

```bash
node -v
```

اگه یه چیزی مثل `v20.11.0` یا بالاتر دیدی، عالیه.

### قدم ۱ — پروژه رو بگیر و پکیج‌ها رو نصب کن

```bash
git clone https://github.com/MrMatin0/elegram.git
cd elegram
npm install
```

اگه `git` نداری، از صفحه گیت‌هاب دکمه **Code → Download ZIP** رو بزن، فایل رو از حالت زیپ دربیار، بعد ترمینال رو داخل همون پوشه باز کن و فقط `npm install` رو اجرا کن.

### قدم ۲ — از تلگرام دو تا کد بگیر (API_ID و API_HASH)

این دو تا مثل «شناسنامه» برنامه‌ات هستن و تلگرام مجانی میدشون:

1. برو به [my.telegram.org](https://my.telegram.org) و با شماره تلگرام خودت وارد شو.
2. روی **API development tools** کلیک کن.
3. فرم رو پر کن (اسم اپ هر چیزی می‌تونه باشه، مثلاً `elegram`).
4. دو تا مقدار به اسم `api_id` و `api_hash` می‌بینی. اینا رو یه جا کپی کن، بهشون نیاز داریم.

### قدم ۳ — فایل تنظیمات رو بساز

توی پوشه پروژه یه فایل به اسم `.env.example` هست. یه کپی ازش بگیر و اسم کپی رو بذار `.env`:

```bash
# مک و لینوکس
cp .env.example .env

# ویندوز
copy .env.example .env
```

حالا `.env` رو با هر ویرایشگر متنی باز کن و `API_ID` و `API_HASH` رو با همون مقادیر قدم ۲ پر کن. `SESSION` رو فعلاً خالی بذار، قدم بعدی درستش می‌کنه.

> 🔒 فایل `.env` اطلاعات خصوصی توئه. هیچ‌وقت جایی آپلودش نکن و به کسی نده.

### قدم ۴ — یه بار به اکانتت لاگین کن

```bash
npm run login
```

ازت می‌پرسه:

- **شماره تلفن** — با کد کشور، مثلاً `+98912...`
- **کد تایید** — همون کدی که تلگرام برات می‌فرسته
- **رمز دو مرحله‌ای** — اگه فعال نکردی، فقط Enter بزن

آخرش یه رشته طولانی و عجیب‌غریب برات چاپ می‌شه. **کاملش رو کپی کن** و توی فایل `.env` بذارش جلوی `SESSION=`. یعنی این‌شکلی:

```
SESSION=1BQANOTEuMTA4LjU2LjE...
```

این کار فقط یه بار لازمه. این رشته حکم «کلید ورود» رو داره، پس مثل رمز عبور ازش مراقبت کن.

### قدم ۵ — اجراش کن

```bash
npm start
```

همین! حالا برو توی تلگرام، **Saved Messages** خودت رو باز کن و بنویس `/ping`. اگه پیامت تبدیل شد به یه کارت با اطلاعات اتصال، یعنی همه‌چیز درست کار می‌کنه. 🎉

> 💡 تا وقتی این ترمینال بازه، Elegram روشنه. اگه ببندیش خاموش میشه. برای اینکه ۲۴ ساعته روشن بمونه، بخش دیپلوی روی Railway رو ببین.

## 🎮 دستورات

دستورات رو مثل یه پیام معمولی می‌فرستی (معمولاً توی Saved Messages خودت). پیامت جای اینکه بمونه، تبدیل به جواب میشه.

| دستور | کارش چیه؟ |
| :--- | :--- |
| `/save` | **مهم‌ترین دستور.** روی اون عکس/ویدیو/فایلی که می‌خوای ریپلای کن و بفرست `/save`. همین. |
| `/auto on` | «از این به بعد هر رسانه‌ای توی این چت اومد، خودکار سیو کن.» |
| `/auto off` | خاموش کردن حالت خودکار برای همون چت. |
| `/autolist` | ببین کدوم چت‌ها حالت خودکارشون روشنه. |
| `/status` | چند فایل سیو شده، چه حجمی، چند تا در صف، مصرف حافظه. |
| `/ping` | چک کن که زنده و وصله. |
| `/help` | راهنمای کامل داخل تلگرام. |

**دو نکته:**

- برای عکس‌های **یک‌بارمصرف** لازم نیست کاری بکنی. به محض رسیدنشون خودکار و با بالاترین اولویت سیو میشن.
- `/auto` رو داخل Saved Messages نمی‌تونی روشن کنی (منطقی هم نیست، خودش مقصد آرشیوه). توی بقیه چت‌ها و کانال‌ها کار می‌کنه.

## ⚙️ تنظیمات فایل `.env`

فقط سه ردیف اول اجباری‌اند. بقیه رو اگه دست نزنی، همه‌چیز با مقدار پیش‌فرض درست کار می‌کنه.

| اسم | لازمه؟ | چیکار می‌کنه |
| :--- | :---: | :--- |
| `API_ID` | ✅ | از my.telegram.org |
| `API_HASH` | ✅ | از my.telegram.org |
| `SESSION` | ✅ | خروجی `npm run login` |
| `STORAGE_PEER` | ❌ | فایل‌ها کجا ذخیره شن. پیش‌فرض `me` یعنی Saved Messages. می‌تونی یوزرنیم یه کانال شخصی خودت رو بدی، مثل `@myarchive`. اگه در دسترس نباشه، خودش برمی‌گرده سراغ Saved Messages. |
| `PORT` | ❌ | پورت وب‌سرور سلامتی (پیش‌فرض `3000`) |
| `DATA_DIR` | ❌ | محل ذخیره تنظیمات و آمار (پیش‌فرض `./data`) |
| `DEVICE_MODEL` | ❌ | اسمی که توی لیست دستگاه‌های تلگرامت نشون داده میشه |
| `CONCURRENCY` | ❌ | چند فایل هم‌زمان سیو شه (پیش‌فرض `2`، بین ۱ تا ۸). زیاد نکن، تلگرام خوشش نمیاد. |
| `ALBUM_WINDOW_MS` | ❌ | چند میلی‌ثانیه صبر کنه تا کل آلبوم برسه (پیش‌فرض `1200`) |
| `TIMEZONE` | ❌ | منطقه زمانی تاریخ‌ها (پیش‌فرض `Asia/Tehran`) |
| `LOG_LEVEL` | ❌ | چقدر توی ترمینال حرف بزنه: `silent`، `error`، `warn`، `info`، `debug` (پیش‌فرض `info`) |

## ☁️ روشن نگه داشتنش ۲۴ ساعته (با Railway)

اگه نمی‌خوای کامپیوترت همیشه روشن باشه، می‌تونی مجانی بذاریش روی [Railway](https://railway.app):

1. یه کپی (Fork) از این پروژه توی گیت‌هاب خودت بساز.
2. توی Railway بزن **New Project → Deploy from GitHub repo** و همون پروژه رو انتخاب کن.
3. برو تب **Variables** و این سه تا رو اضافه کن: `API_ID`، `API_HASH`، `SESSION`.
4. Deploy کن. تمام. (فایل `nixpacks.toml` خودش نسخه درست Node رو ست می‌کنه.)

یه آدرس `/health` هم داره که می‌تونی باهاش چک کنی سرویس بالاست یا نه.

## 🩺 مشکل خوردی؟

**«متغیر محیطی API_ID تنظیم نشده است»**
فایل `.env` رو نساختی یا خالیه. برگرد به قدم ۳.

**«متغیر SESSION خالی است»**
قدم ۴ رو انجام بده و اون رشته طولانی رو داخل `.env` بذار.

**`npm` یا `node` شناخته نمی‌شه**
Node.js نصب نیست یا بعد از نصب، ترمینال رو نبستی. ترمینال رو ببند و از اول باز کن.

**پیام میدم ولی هیچ اتفاقی نمی‌افته**
مطمئن شو `npm start` هنوز داره اجرا میشه و ترمینال رو نبستی. اول با `/ping` تست کن.

**می‌گه کد اشتباهه یا لاگین نمیشه**
`API_ID` و `API_HASH` رو دوباره از my.telegram.org چک کن. حتی یه کاراکتر اضافه یا فاصله هم کافیه که کار نکنه.

**سیو کردن وسط کار متوقف شد یا کند شد**
احتمالاً تلگرام موقتاً محدودت کرده (FloodWait). خودش صبر می‌کنه و مجدد تلاش می‌کنه، پس فقط بذار کارش رو بکنه. برای اینکه کمتر پیش بیاد، `CONCURRENCY` رو بذار `1`.

**فایل‌های بزرگ خیلی طول می‌کشن**
طبیعیه. Elegram اول دانلود می‌کنه بعد آپلود، پس سرعت اینترنتت مستقیم روش اثر داره.

## 🧱 ساختار پروژه

اگه فقط می‌خوای استفاده کنی، لازم نیست اینو بخونی. برای کسیه که می‌خواد کد رو دست بگیره:

```
src/
├── index.js              # نقطه شروع برنامه: اتصال، راه‌اندازی، خاموشی امن
├── config.js             # خوندن و اعتبارسنجی متغیرهای .env
├── login.js              # اسکریپت ساخت SESSION
├── store.js              # ذخیره تنظیمات و آمار روی فایل JSON
├── server.js             # وب‌سرور کوچک برای چک سلامت سرویس
├── handlers/
│   ├── messages.js       # تشخیص اینکه هر پیام چیه (دستور / رسانه / یک‌بارمصرف)
│   └── commands.js       # منطق هر دستور
├── services/
│   ├── archiver.js       # موتور اصلی: دانلود ← آپلود، با نمایش پیشرفت
│   ├── mediaInfo.js      # تشخیص نوع رسانه، نام فایل، لینک منبع
│   ├── queue.js          # صف کارها با اولویت
│   └── albums.js         # جمع کردن آلبوم‌های چندتایی
├── ui/
│   └── cards.js          # قالب پیام‌ها و کارت‌های فارسی
└── utils/
    ├── format.js         # فرمت حجم، مدت زمان و تاریخ
    ├── logger.js         # لاگ‌های ترمینال
    └── retry.js          # تلاش مجدد هوشمند وقتی تلگرام یا شبکه اذیت می‌کنه
```
